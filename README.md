# カイシャイン分析 クロウドリサーチ
## Instagram「1ヶ月で1万フォロワー」を狙うためのアカウントリサーチと実行キット

作成：2026-11-26（取得日も同日）／作成者：Claude（Claude Code）

### これは何か
- **実データ**：伸びたInstagramアカウント12件（2026年10〜11月にリストへ掲載された、お金・ダイエット・美容・その他の4ジャンル）を、実際のプロフィールとリール再生数で調べた結果
- **方法**：同じ質のリサーチを、どのジャンル・どのアカウントでも人やAIが再現できる手順書・計算スクリプト・チェックリスト
- **実行キット**：アカウント設計テンプレ、型別のリール台本、30日ロードマップ、他のAIにそのまま渡せるプロンプト集
- **4つのノウハウを統合**：運用バイブル（Instagram & Threads 運用完全攻略バイブル 2026）／シンスレッズ／まな式マネタイズ／レオパック（[ruru0707runa/leo](https://github.com/ruru0707runa/leo)）の要点を、実データで裏付けて1つの型にまとめています

### 誰向けか
- フォロワー0〜1,000人で、1ヶ月で1万人を狙いたい運用者
- 運用代行者（クライアントのジャンルでリサーチを回す）
- AIにリサーチや運用計画を任せたい人

### 使い方
- **自分で使う**：`00` → `06` → `07` → `08` の順に読み、テンプレを埋める
- **AIに任せる**：このリポジトリのURLを渡し、`09` のP0から順に貼る
- **自分のジャンルで作り直す**：`05` の手順で12件を調べ、`accounts.tsv` を入れ替える

### 精読ルール（他のAIへ）
1. 数字は2026-11-26時点にプロフィールとリール一覧で見えた値です。投稿日やフォロワーの推移は取れていません。「1ヶ月で1万人に届いた」とは書いていません。**掲載時点で1万人以上**という事実だけです。
2. ノウハウ由来の数字（3秒維持率65%、評価期間48〜72時間など）は各教材の主張で、Instagram公式の仕様ではありません。
3. 他アカウントの台本・画像・キャプションを写さないこと。借りるのは構造だけです。
4. 健康・美容・お金のジャンルでは、断定や煽りをしないこと。
5. 成果を保証するものではありません。

### 一行結論
**少ない投稿で大きく伸びたアカウント（はっちゃん14本で4.6万人、かいみ35本で2.8万人）は、「替えのきかないキャラクター」か「続きが気になる連載」を持っていて、フォロワーの200倍を超える大ヒットを1本出していました。12件の大半は、プロフィールの1行目で「何が届くか」を数字で約束しています。1万人への近道は、再生を伸ばすことと同じくらい、プロフィール訪問をフォローに変える仕組みを先に作ることです。**
