### このリポジトリは何か
「爆伸びアカウント集」（スプレッドシート）のうち、**ジャンル欄が2026年10月・11月の掲載**になっているアカウント（お金・ダイエット・美容・その他の4タブ、計12件）を、実際のInstagramプロフィールとリール再生数で調べた結果です。
そのうえで、手元にある4つのノウハウ（運用バイブル／シンスレッズ／まな式／レオパック）と照らし合わせ、**どう投稿すれば1ヶ月で1万フォロワーに届くか**を、汎用の型と shiba_ai_kenko への当てはめの両方で書いています。

### 他のAIへの精読ルール
1. 数字は **2026-11-26 時点にプロフィールとリール一覧で見えた値**です。投稿日やフォロワー推移は取れていません（`04` 参照）。「1ヶ月で1万人に届いた」とは書いていません。**掲載時点で1万人以上**という事実だけです。
2. ノウハウ由来の数字（3秒維持率65%など）は各教材の主張で、Instagram公式の仕様ではありません。
3. 他アカウントの台本・画像・キャプションを写さないこと。盗むのは構造だけです。
4. 健康・美容ジャンルに当てはめるときは、薬機法に合わせて断定を避けます（「〜と言われています」）。

### 一行結論
**少ない投稿で大きく伸びたアカウント（はっちゃん14本で4.6万人、かいみ35本で2.8万人）は、「替えのきかないキャラクター」か「続きが気になる連載」を持っていて、フォロワーの200倍を超える大ヒットを1本出していました。12件の大半は、プロフィールの1行目で「何が届くか」を数字で約束しています。** 再生を伸ばす力はshibaにもすでにあります（フォロワー比110倍）。足りないのはフォローに変える仕組みです。
